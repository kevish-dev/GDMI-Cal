# Quick Start Guide: Jewelry Tag Scanning

## How to Scan Jewelry Tags

### Step 1: Select Jewelry Type
Choose between:
- **Gold Jewelry** - For gold ornaments with or without stones
- **Diamond Jewelry** - For jewelry with diamonds

### Step 2: Capture Tag Images

#### Best Practices
✅ **Good Lighting**: Natural light or bright white light works best
✅ **Clear Focus**: Ensure text is sharp and readable
✅ **Flat Angle**: Hold camera straight, perpendicular to tag
✅ **Fill Frame**: Get close enough so tag fills most of the frame
✅ **No Glare**: Avoid reflections from glossy tags
✅ **Steady Hand**: Hold still or use a surface to stabilize

#### What to Avoid
❌ Blurry or out-of-focus images
❌ Dark or dim lighting
❌ Angled shots that distort text
❌ Partial tag coverage
❌ Glare or reflections covering text

### Step 3: Review Extracted Information

The AI will automatically extract:

#### For Gold Jewelry
- Gross Weight (G.W) - Total weight
- Net Weight (N.W) - Pure gold weight
- Stone Weight (STN/KUN) - Weight of stones/kundan
- Purity (22K/18K/14K) - Gold purity
- Item Code - Product identifier

#### For Diamond Jewelry
- Gold Weight (G.W/N.W) - Gold portion weight
- Diamond Weight - In carats
- Stone Details - Type, count, weight
- Color/Clarity - If mentioned
- Purity - Gold purity
- Item Code - Product identifier

### Step 4: Answer Verification Questions

#### Gold Jewelry Questions
1. **Buy-back guarantee**: Does your jeweler offer 100% buy-back on gold weight?
2. **Raw form**: Did you see the jewelry being made from raw gold?

#### Diamond Jewelry Questions
1. **Appreciation**: Can you sell the diamond later at appreciated value?
2. **Certification**: Is it IGI certified or self-certified?

### Step 5: Set Making Charges

#### Gold Jewelry
- Select category: Chains, Plain, Temple, Italian
- Making charge calculated as percentage of gold value

#### Diamond Jewelry
- Making charge: ₹800 per gram (default)
- Can be adjusted if needed

### Step 6: Review Price Breakdown

Check the calculated price showing:
- Gold value (weight × rate)
- Diamond value (weight × rate) - if applicable
- Making charges
- Final price (no GST added)

## Understanding Tag Formats

### Common Abbreviations

| Text on Tag | Means | Example |
|------------|-------|---------|
| G.W or G.Wt | Gross Weight (total) | G.W: 117.110 |
| N.W or N.Wt | Net Weight (gold only) | N.W: 97.660 |
| STN or STONES | Stone weight | STN: 16.93 |
| KUN or KUND | Kundan weight | KUN: 3.63 |
| RD | Round Diamond | RD: PC-104\2.01 |
| PC | Piece Count | PC-249 (249 pieces) |
| CS | Color Stone | CS: 2.15 |

### Tag Colors You Might See

🟢 **Green/Mint Tags**: Usually with QR codes
🩷 **Pink/Purple Tags**: Premium items, printed text
🔵 **Blue/Light Tags**: Standard with barcodes
⚪ **White Tags**: Basic printed tags

All colors are supported!

### Special Notations

**Backslash (`\`) Separator**
- `1.250\1000` = Two values (1.250 + 1.000 = 2.250 total)
- `PC-104\2.01` = 104 pieces, weighing 2.01 carats total

**Multiple Stone Types**
```
STN: 1.250
KUN: 6.245
ICS: 2.950
```
Each will be extracted separately and totaled

## Troubleshooting

### Tag Not Reading?
1. **Improve lighting** - Try different light angles
2. **Clean tag** - Wipe any dust or fingerprints
3. **Get closer** - Fill more of the frame with the tag
4. **Hold steady** - Wait for focus before capturing
5. **Try both sides** - Upload top and bottom views

### Missing Information?
- The system extracts only visible information
- Some fields may be empty if not on tag
- Check "Raw Text" section for any additional details
- You can manually verify and proceed

### Incorrect Values?
- Review extracted data before proceeding
- Retake photo with better clarity
- Ensure tag is not damaged or faded
- Contact support if persistent issues

## Pro Tips

💡 **For Best Results**
1. Clean the tag surface before scanning
2. Use a white background when possible
3. Capture both sides if tag has information on both
4. Natural daylight provides best results
5. Hold camera at arm's length for stability

💡 **Quick Checks**
- Net Weight should be less than Gross Weight
- Stone Weight = Gross Weight - Net Weight
- Purity should be 22K, 18K, or 14K
- Item codes are unique identifiers

💡 **Time Savers**
- Good lighting reduces retakes
- Clear focus eliminates errors
- Both views provide complete data
- Review before proceeding saves time

## Understanding Your Results

### Gold Jewelry Breakdown
```
Gold Value = Net Weight × Current Gold Rate
Making Charges = Gold Value × Making Charge %
Final Price = Gold Value + Making Charges
```

### Diamond Jewelry Breakdown
```
Gold Value = Net Gold Weight × Gold Rate
Diamond Value = Diamond Weight × Diamond Rate
Making Charges = Net Gold Weight × ₹800/gram
Final Price = Gold Value + Diamond Value + Making Charges
```

### Making Charge Categories

**Gold Categories:**
- **Chains**: Higher percentage for intricate work
- **Plain**: Standard charges
- **Temple**: Traditional designs
- **Italian**: Premium imported designs

**Diamond:**
- Fixed rate per gram of gold
- Reflects setting complexity

## Need Help?

### Common Questions

**Q: Can I scan handwritten tags?**
A: Best results with printed tags. Handwritten may need manual entry.

**Q: What if tag is damaged?**
A: Try to capture readable portions. Manual entry may be needed.

**Q: Multiple tags for one item?**
A: Scan the main tag with weight/purity information.

**Q: QR code scanning?**
A: QR codes are detected but text extraction focuses on printed info.
